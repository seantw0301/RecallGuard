# RecallGuard

> Counterfactual memory replay for personal AI. Find the memory that changed the agent's mind.

Hackathon: Nebius × NVIDIA Global AI Hackathon — Personal AI track.

When a personal AI makes a bad decision, RecallGuard replays the exact memory context with **Nemotron** (via Nebius Token Factory), removes one memory at a time, and shows which memory changed the action — then lets a human quarantine it.
